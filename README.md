## Activity notes
## Activities 1, 2, and 3
### Activity 1 - Presentation design principles
- **Activity 1 - Presentation design principles** (`Design Principles/`): slide work that uses hierarchy, contrast, alignment, and formatting so each screen carries one clear claim.
- **Activity 2 - Color palette and typography** (`Palette & Typography/`): the set above (navy, teal, coral, vital red, ivory) with Montserrat + Arvo and the 60 / 25 / 10 / 5 usage split. Source files: `Activity 2_Gonzaga.zip`.
- **Activity 3 - Infographics and mini project** (`Infographics and Project Doc/`): social graphic (`Infographic_GONZAGA.png`) and process write-up (`Project Documentation_GONZAGA.pdf`) built on the same colors and type.
Visual hierarchy, contrast, alignment, and formatting are applied so each slide carries one primary claim. Size, weight, and color rank information; a consistent left rail and even gutters keep the deck feeling like a system rather than separate posters.
### Activity 2 - Color palette and typography
A constrained dark system: deep ink surfaces, cyan / violet / fuchsia accents, and two type families (display headings vs. body copy). HEX and RGB values, plus usage rationale, are documented in the Activity 2 package.
### Activity 3 - Infographics and mini project
Feed and story graphics share one visual language. The PNG infographic is the public-facing asset; the PDF records concept, visual choices, and the creative workflow.
### Wrap-up - Why presentation design matters
Presentation design is how attention is allocated and how complex IT work becomes usable for an audience. Key takeaways: **engagement** (one claim at a time), **clarity** (contrast, alignment, limited palette), and **visual experience** (deliberate type and color, not decoration).
